1.config/: Security 필터 체인 설정, 비밀번호 암호화 객체(PasswordEncoder) 생성 등 전체 애플리케이션 설정을 관리합니다.
2.controller/: 사용자의 HTTP 요청(GET,POST)을 수신하고, 화면(templates/..) 반환 및 API 응답을 제어합니다.
3.dto/: 계층 간(HTML ↔ Controller ↔ Service) 데이터 전송 시 필요한 순수 데이터 객체입니다.
4.service/: 회원 중복 검사, 비밀번호 인코딩, 게시글 권한 체크 등 실제 비즈니스 규칙과 연산을 수행합니다.
5.repository/:JdbcTemplate을 이용해 DB(MySQL / TiDB)에 Direct SQL Query(INSERT,SELECT,UPDATE,DELETE)를 전송합니다.
